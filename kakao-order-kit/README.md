# 카카오톡 발주 키트

거래처(점주)가 **카카오톡 채널**에서 버튼만 눌러 발주하고, 공급사는 **관리자 화면**에서 확인·출고·명세서까지 처리하는 프로그램입니다.
Cloudflare Workers(서버) + D1(데이터베이스) 위에서 돌아가며, 외부 패키지 없이 Node.js 만 있으면 됩니다.

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 점주 | 카카오톡 채널 챗봇 | 품목 골라 담기 · 장바구니 · 주문 확정 · 지난 발주 그대로 · 발주 내역 · 품목 추가 신청 |
| 점주 | 웹 발주서 (카톡 [전체 품목 발주서] 버튼) | 전체 품목을 한 화면에서 +/−, 검색(초성 포함), 박스 + 낱개, 지난 발주 불러오기, 홈 화면 앱 |
| 공급사 | `/admin` 관리자 화면 | 주문 확인 → 출고 · 출고 집계 · 발주 확인서/거래명세서 PDF · 실물 명세서 사진 · 매장 · 품목(엑셀) · 담당자 |
| 점주·담당자 | 카카오톡 (선택) | 접수·확인·출고·취소 알림, 담당자에게 새 발주 목록 — 카카오 Event API (건당 15원) |

**들어 있지 않은 것**: 카카오 채널·챗봇·키, 비즈월렛, 도메인. 아래 순서대로 각자 만들어 연결합니다.

---

## 0. 준비물

- Node.js **22.13 이상** (https://nodejs.org → LTS)
- Cloudflare 계정 (무료) — https://dash.cloudflare.com
- 카카오톡 채널 (무료) — https://business.kakao.com
- (카톡 자동 알림을 쓰려면) 사업자등록 · 카카오 비즈니스 인증 · 비즈월렛 충전

## 1. Cloudflare 에 올리기

1. Windows: 압축을 푼 `kakao-order-kit` 폴더의 **`deploy-cloudflare.bat`** 더블클릭
   Mac/Linux: 이 폴더에서 `node scripts/deploy-cloudflare.js`
2. 브라우저가 열리면 Cloudflare 로그인 → **Allow**
3. 관리자 비밀번호(8자 이상) 입력
4. 끝나면 **관리자 주소**와 **오픈빌더 스킬 URL** 이 나옵니다 (스킬 URL 은 클립보드에 복사됨)
   - 주소: `https://kakao-order.<내 계정>.workers.dev`
   - 스킬 URL: `https://…/kakao/skill?key=<자동으로 만든 키>`

코드를 고친 뒤 같은 파일을 다시 실행하면 업데이트됩니다. 데이터(D1)는 그대로 남습니다.
스킬 URL 은 관리자 **[매장] 탭 맨 아래**에서도 언제든 복사할 수 있습니다.

> 둘러보기용 샘플 품목·매장이 필요하면 `wrangler.toml` 의 `SEED_SAMPLE = "1"` 로 배포하세요. 운영 전에는 `"0"`.

## 2. 관리자 첫 설정 (`/admin` → [설정])

1. **회사 정보**: 서비스 이름(화면 제목·카톡 문구·홈 화면 아이콘 이름), 상호, 사업자등록번호, 대표, 연락처, 주소, 통신판매업 신고번호, 이메일, 입금 계좌
   - 확인서·명세서 공급자 칸과 모든 화면 하단 사업자 정보에 들어갑니다 (입금 계좌는 문서에만).
2. **주문 마감 · 배송**: 마감 시각(이후 주문은 다음 영업일 접수), 배송 소요일, 주말 제외
3. **낱개 단가 자동 계산**: 낱개 단가를 비운 품목에 더할 비율 (기본 10%)
4. **[품목]** → 엑셀 양식 받기 → 작성 → 엑셀 파일 올리기
   - 분류는 카페 / 스낵 / 음료, 업종별 기본 분류는 카페 → 카페, 사우나 → 스낵, 식당 → 음료
   - 다른 분류는 점주가 신청하고 [품목 승인] 탭에서 승인해야 보입니다.

## 3. 카카오톡 채널 + 챗봇 연결

1. https://business.kakao.com 에서 **카카오톡 채널** 만들기 (예: `@행복상회`)
2. https://chatbot.kakao.com (카카오 i 오픈빌더) → **봇 만들기** → 운영 채널에 위 채널 연결
3. **스킬 → 생성**: 이름 `발주서버`, URL = 1단계의 스킬 URL → 저장
4. **시나리오 → 블록 추가 `발주`**: 파라미터 설정의 스킬 `발주서버` → 봇 응답 **스킬데이터 사용** → 저장
5. **폴백 블록**, **웰컴 블록**: 같은 방법으로 스킬 `발주서버` + 스킬데이터 사용 (연결 코드 입력·첫 인사가 여기로 들어옵니다)
6. **발주 블록 ID 넣기**: 발주 블록을 열면 주소가 `…/intent/<블록ID>` → 그 값을 `wrangler.toml` 의 `BLOCK_ID` 에 넣고 1단계를 다시 실행
   - 모든 버튼이 이 블록으로 돌아와 서버가 다음 화면을 정합니다. 비어 있으면 버튼이 동작하지 않습니다.
7. 오픈빌더 **[배포]**

점검: 채널 채팅창에 `링크점검` 을 보내면 링크 버튼이 열리는지 시험하는 화면이 나옵니다.

## 4. 점주 · 담당자 연결

- **점주**: 관리자 [매장] → 매장 추가 → **연결 코드 6자리** → 점주가 채널을 친구 추가하고 채팅창에 입력. 코드는 한 번 쓰면 사라지고 [연결 코드]로 새로 받습니다. 지점이 여러 곳이면 코드마다 추가 연결되고 [매장 바꾸기]로 오갑니다.
- **지점 담당자(공급사 직원)**: [매장] → 지점 담당자 추가 → **연결 코드 8자리** → 담당자가 같은 채널 채팅창에 입력. 매장 목록 [담당자] 칸에서 매장마다 지정하면, 그 매장 발주가 담당자 카톡으로 갑니다 (6단계 Event API 필요).
- 발주서 링크는 1년 유효. 잃어버리면 [발주서 링크 → 링크 바꾸기]로 예전 링크를 모두 막을 수 있습니다.

## 5. 매일 쓰는 흐름

1. [주문] → **[확인하고 카톡 알림]** → [출고 집계]로 피킹 → **[출고 처리]**
2. 회사 프로그램에서 뽑은 종이 명세서는 주문 카드 **[실물 명세서 올리기]** (사진, 최대 5장)
3. 품절 등으로 못 보내면 **[주문 취소]**
4. 카톡 자동 알림을 안 쓰면 처리 후 **답장 문구 창**이 뜹니다 → [복사하고 채팅방 열기] → 카카오 비즈니스 1:1 채팅에 붙여넣기 (무료). 매장 상세에 채팅방 주소를 저장하면 바로 그 방이 열립니다.

## 6. (선택) 카톡 자동 알림 — 카카오 Event API

관리자가 확인·출고·취소를 누르거나 점주가 발주서로 주문하면, 점주·담당자 카톡으로 카드가 **바로** 갑니다.
비용: **알림 1번 × 받는 사람 1명당 15원(VAT 별도)**, 전송 성공 건만 비즈월렛에서 차감.

1. **카카오 디벨로퍼스** https://developers.kakao.com → 앱 만들기 → **비즈니스 정보 심사** 신청·승인
2. 같은 앱 → 추가 기능 **[카카오톡 채널 연결]** 신청 → 3단계 채널 선택 → 앱 화면에 **대표 채널**로 보이면 완료
   - 오픈빌더 [설정] → 운영 채널의 **연결된 App** 에 이 앱이 보여야 합니다.
3. **비즈월렛**: business.kakao.com → 비즈월렛 만들기 → 캐시 충전 → **챗봇에도 연결** (오픈빌더 화면 안의 월렛 메뉴에서 "현재 자산" = 봇이 연결되어야 함)
4. **알림 스킬**: 오픈빌더 [스킬] → 생성 → 이름 `발주알림`, URL = 스킬 URL 끝에 **`&ev=1`** 을 붙인 주소 (관리자 [설정] → 카톡 자동 알림에서 복사 가능), 헤더는 비우고 기본 스킬로 설정하지 않음
5. **알림 블록**: [시나리오] → 블록 `주문알림` 추가 → 사용자 발화 비움 → 스킬 `발주알림` → 스킬데이터 사용 → 저장 → 오른쪽 위 `⋯` → **이벤트 설정**에 `order_notice` 입력 후 **엔터** → 확인 → 저장 → **[배포]**
6. 관리자 [설정] → 카톡 자동 알림: **봇 ID**(오픈빌더 주소 `bots/` 뒤 값), **REST API 키**(디벨로퍼스 → 앱 → 플랫폼 키 → REST API 키), **이벤트 이름** `order_notice` → 저장
7. 관리자 [매장] → 카톡이 연결된 매장 → **[알림 테스트]**

| [알림 테스트] 오류 | 원인 | 고칠 곳 |
|---|---|---|
| `Invalid appKey` | 키가 다른 앱/다른 종류이거나, 채널에 앱이 연결되지 않음 | 2단계 채널 연결 · 6단계 REST API 키 |
| `Invalid Event name` | 이벤트가 등록·배포되지 않음 | 5단계 (엔터로 등록 → 저장 → 배포) |
| `Wallet not found` | 봇에 월렛이 연결되지 않음 | 3단계 |
| `카카오 서버가 응답하지 않아요` | 일시 지연 | 잠시 후 다시 |

- 채널을 친구로 추가한 사람에게만 갑니다 (차단하면 실패, 과금 없음).
- 실패하면 관리자 화면에 이유와 **답장 문구 창**이 떠서 직접 보낼 수 있고, [주문] 탭 '새 소식'에도 남습니다.

## 7. (선택) 자체 도메인

카카오톡 링크 버튼은 `workers.dev` 주소를 막는 경우가 있어 자체 도메인을 권장합니다.

1. Cloudflare 에 도메인 추가 (구매하거나 기존 도메인 이전)
2. `wrangler.toml` 의 `routes` 주석을 풀고 `order.example.com` 을 내 주소로, `PUBLIC_URL` 도 같은 주소로
3. 1단계 다시 실행 → 오픈빌더 두 스킬(`발주서버`, `발주알림`)의 URL 앞부분을 새 주소로 바꾸고 배포

## 8. (데모) 내 컴퓨터에서 켜기

서버 없이 둘러볼 때: Mac `bash start-mac.sh`, Windows `start-windows.bat` 더블클릭.
cloudflared 터널로 임시 https 주소를 만들고 관리자 비밀번호·스킬 키를 `data/settings.env` 에 저장합니다.
창을 닫으면 멈추고, 켤 때마다 주소가 바뀌므로 운영은 1단계(Cloudflare)로 하세요.

## 설정값 (환경 변수 · `wrangler.toml` 의 `[vars]`)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PUBLIC_URL` | (접속 주소) | 발주서 링크·스킬 URL 에 쓰는 외부 주소 |
| `BLOCK_ID` | | 오픈빌더 `발주` 블록 ID (3-6단계) |
| `MIN_ORDER` | 0 | 최소 발주 금액(원) |
| `SEED_SAMPLE` | 0 | 1 = 품목이 없을 때 샘플 데이터 |
| `ADMIN_PASSWORD` | | 관리자 비밀번호 (Cloudflare 는 배포 때 비밀값으로 저장) |
| `SKILL_KEY` / `SECRET` | (자동 생성) | 스킬 URL 키 · 링크 서명 키. 비우면 처음 켤 때 DB 에 만들어 보관 |
| `GUEST_URL` / `GUEST_LABEL` | | 연결 안 된 손님에게 보여 줄 안내 버튼 (예: 쇼핑몰) |
| `PORT` · `DATA_DIR` | 8080 · data/ | 내 컴퓨터에서 켤 때만 |
