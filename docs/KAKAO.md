# 카카오 비즈니스 발주 관제 — 만드는 순서

점주는 카카오톡 **BevFlow 채널**에서 버튼만 눌러 발주하고, 운영자는 **운영 콘솔**과 **내 카카오톡(나와의 채팅)**으로 결과를 받습니다.
이 문서는 계정 개설부터 첫 발주 점검까지 순서대로 적었습니다. `[붙여넣기]` 표시는 그대로 복사해 넣으면 되는 값입니다.

| 구분 | 누가 | 어디서 |
|---|---|---|
| 서버·화면·챗봇 응답·알림 로직 | BevFlow 코드 (이 저장소) | 이미 들어 있음 |
| 카카오 계정·채널·앱·봇·알림톡 계약 | **대표/운영 담당자 본인** | 카카오 사이트 (본인 카카오 계정 로그인, 휴대폰 인증, 사업자 서류 필요) |
| 콘솔 설정 입력 | 운영 담당자 | BevFlow 운영 콘솔 |

## 전체 일정

| 주차 | 할 일 | 막히는 지점 |
|---|---|---|
| 1주 | 0 준비물 · 1 서버 · 2 채널 개설 → 비즈니스 인증 신청 | 비즈니스 채널 심사 (수일) |
| 1주 | 3 카카오 디벨로퍼스 앱 · 4 챗봇 | 없음 (심사 없이 가능) |
| 2주 | 5 알림톡 딜러사 계약 → 템플릿 심사 | 템플릿 심사 (영업일 약 2일, 반려 시 재심사) |
| 2주 | 6 콘솔 입력 · 7 관리자 알림 연결 · 8 점검 | 없음 |
| 3주~ | 9 매장 온보딩 (연결 코드) · (선택) 전화번호 동의항목 심사 | 전화번호 심사 (기간 별도) |

## 0. 준비물

- 사업자등록증 (PDF/이미지), 통신판매업 신고증(있으면), 식품 관련 인허가증(식품 유통이면)
- 대표 또는 담당자 카카오 계정 (휴대폰 인증된 계정). 회사 공용 계정을 새로 만드는 것을 권장
- 운영 서버의 HTTPS 주소 (예: `https://ops.회사도메인.kr`) — 카카오에 등록하는 모든 주소가 이 도메인을 씁니다
- 채널 프로필 이미지 640×640 PNG, 배경 이미지(선택)

## 1. 운영 서버 먼저 (HTTPS)

카카오 스킬 URL, 로그인 Redirect URI, 알림 버튼 링크가 모두 이 주소를 가리키므로 가장 먼저 합니다.

1. `deploy/README.md` 순서대로 서버를 올리고 HTTPS(Caddy)를 붙입니다.
2. 콘솔 [관리 → 운영 설정 → 연동 → 외부 접속 주소]에 `https://ops.회사도메인.kr` 을 넣고 저장합니다.
3. 브라우저에서 `https://ops.회사도메인.kr/healthz` 가 `{"ok":true…}` 를 보여 주면 됩니다.

## 2. 카카오톡 채널 개설 (카카오비즈니스)

사이트: https://business.kakao.com

1. 카카오 계정으로 로그인 → **카카오비즈니스 통합 회원** 전환 동의.
2. [내 비즈니스 → 채널 → 새 채널 만들기]
   - 채널 이름 `[붙여넣기]` `BevFlow 발주`
   - 검색용 아이디 `[붙여넣기]` `bevflow` (사용 중이면 `bevflow_order` 등)
   - 소개글 `[붙여넣기]` `카페·사우나·식당 납품 발주 채널입니다. 버튼만 눌러 발주하고 배송 소식을 받아 보세요.`
   - 카테고리: 도소매 > 식품 유통(가장 가까운 항목)
3. [채널 → 관리 → 상세 설정]
   - **1:1 채팅: 사용** (챗봇이 이 채팅방에서 응답합니다)
   - 채널 공개·검색 허용: B2B 전용이면 **검색 비공개**로 두고 링크로만 추가받아도 됩니다
4. [채널 → 관리 → 관리자] 운영팀원 카카오 계정 초대 (마스터 1명 + 매니저)
5. **비즈니스 인증 채널 신청**: [채널 → 비즈니스 인증] 사업자 정보 입력, 서류 업로드 → 심사 (수일). 알림톡은 인증 채널에서만 보낼 수 있습니다.
6. 채널 홈 주소 `https://pf.kakao.com/_xxxxx` 의 `_xxxxx` 를 메모 → 6단계에서 **채널 ID**로 입력

## 3. 카카오 디벨로퍼스 앱 (카카오 로그인 · 관리자 알림)

사이트: https://developers.kakao.com

1. [내 애플리케이션 → 애플리케이션 추가하기] 앱 이름 `BevFlow 발주`, 회사명, 아이콘.
2. [앱 설정 → 비즈니스] **비즈 앱 전환** (사업자 정보). 동의항목 확장·채널 연결에 필요합니다.
3. [앱 설정 → 플랫폼 → Web] 사이트 도메인 `[붙여넣기]` `https://ops.회사도메인.kr`
   - 관리자 카톡 알림의 버튼 링크도 이 도메인이어야 열립니다.
4. [제품 설정 → 카카오 로그인] **활성화 ON**
   - Redirect URI `[붙여넣기]` `https://ops.회사도메인.kr/k/callback` (콘솔 [품목 승인·카카오 → 카카오 로그인]에 표시된 값과 같아야 함)
5. [카카오 로그인 → 동의항목]
   | 항목 | 설정 | 쓰임 |
   |---|---|---|
   | 닉네임 (profile_nickname) | 필수 동의 | 연결된 계정 표시 |
   | 카카오톡 메시지 전송 (talk_message) | 선택 동의 | **관리자 카톡 알림** (나에게 보내기) |
   | 카카오계정(전화번호) (phone_number) | 선택 동의 · **검수 필요** | 사장님 번호로 매장 자동 연결 (없으면 연결 코드로 운영) |
6. [카카오 로그인 → 보안] Client Secret 코드 생성 → **활성화: 사용함** → 값을 서버 환경 변수 `BEVFLOW_KAKAO_CLIENT_SECRET` 에 넣고 재시작.
7. [앱 설정 → 앱 키] **REST API 키** 복사 → 6단계에서 콘솔에 입력
8. [앱 설정 → 카카오톡 채널] 2의 채널 연결 → 카카오 로그인한 점주는 챗봇에서 연결 코드 없이 인식됩니다.

## 4. 챗봇 (카카오 i 오픈빌더 / 챗봇 관리자센터)

사이트: https://chatbot.kakao.com

1. [봇 만들기 → 카카오톡 챗봇] 이름 `BevFlow 발주봇`.
2. [설정 → 카카오톡 채널 연결] 2의 채널 선택 (운영 채널).
3. [스킬 → 생성]
   - 이름 `발주 스킬`
   - URL `[붙여넣기]` 콘솔 [관리 → 품목 승인·카카오 → 오픈빌더 스킬 서버]의 주소 전체 (`…/api/kakao/skill?key=…`). 관리자 계정으로만 보입니다.
   - [기본 스킬로 설정] 체크
4. [시나리오 → 블록 추가] 이름 `발주`
   - 사용자 발화 `[붙여넣기]` (한 줄에 하나)
     ```
     발주
     발주하기
     주문
     장바구니
     발주 현황
     배송 언제
     지난번과 똑같이
     지난번 그대로 확정
     발주서
     품목 추가 신청
     카페 품목
     스낵 품목
     음료 품목
     ```
   - 파라미터 설정 → 스킬 선택: `발주 스킬`
   - 봇 응답: **스킬데이터 사용** → 저장
   - 블록 주소 끝 24자리(블록 ID)를 복사 → 6단계에서 콘솔 [오픈빌더 발주 블록 ID]에 입력.
     블록 ID가 없으면 채팅 속 버튼 발주가 꺼지고 [한눈에 발주하기] 링크만 동작합니다.
5. [기본 시나리오 → 웰컴 블록] 봇 응답을 **스킬데이터 사용 → 발주 스킬**로 (채널에 처음 들어오면 매장 연결 안내가 나옵니다)
6. [기본 시나리오 → 폴백 블록] 같은 스킬 연결 (연결 코드 6자리를 채팅으로 보내면 이 블록으로 들어와 연결됩니다)
7. (권장) 채널 채팅방 하단 메뉴에 `발주하기` 버튼 → `발주` 블록 연결
8. [배포] → 배포하기. 수정할 때마다 다시 배포해야 반영됩니다.
9. 점검: 개인 카카오톡으로 채널 추가 → 채팅방에서 `발주` → "매장 연결이 필요해요" 카드가 나오면 성공.

## 5. 알림톡 (딜러사 계약 · 템플릿 심사)

알림톡은 카카오 공식 딜러사를 통해서만 보냅니다. 비즈니스 인증 채널이 필요합니다.

1. 딜러사 선택 → 계약 → 발신 프로필에 2의 채널 등록.
2. 템플릿 등록 → 심사 (영업일 약 2일). 아래 문구는 서버가 실제로 보내는 문장과 같게 맞춰 두었습니다. `#{…}` 는 변수입니다.
3. 발송 방식: 콘솔 [운영 설정 → 알림 발송 방식 = 웹훅]과 웹훅 URL(딜러사 API를 부르는 중계 서버)을 넣습니다. 요청 형식은 `docs/INTEGRATIONS.md` 2장.

**주의 — 반려되는 문구**: 점주가 요청하지 않은 발주 권유("지금 발주하세요", "아래 버튼으로 주문")는 광고로 보고 반려됩니다. 그래서 운영자가 발주 링크를 알림톡으로 보내는 기능은 넣지 않았습니다(링크는 복사해서 전달).

| 코드 | 버튼 (웹링크 `#{link}`) | 템플릿 문구 `[붙여넣기]` |
|---|---|---|
| `BF_CONFIRM_02` | 확인하기 | `[BevFlow 발주 확정]`<br>`✓ #{code} 발주가 확정됐어요 — #{arrive}`<br>`합계 #{total}`<br>`▶ #{link}` |
| `BF_DELIVERED_01` | — | `[BevFlow 배송 완료]`<br>`#{time}에 주문하신 #{boxes}박스를 하차했어요. 확인 부탁드려요.` |
| `BF_DLVFAIL_01` | — | `[BevFlow 배송 안내]`<br>`오늘 배송을 완료하지 못했어요. 다음 배송일에 다시 방문할게요.` |
| `BF_PAYFAIL_01` | 확인하기 | `[BevFlow 결제 안내]`<br>`#{who}, #{code} 결제가 완료되지 않았어요 (#{reason}).`<br>`결제 수단을 확인해 주시면 바로 출고할게요.`<br>`▶ #{link}` |
| `BF_SHEET_01` | 발주서 확인하기 | `[BevFlow 정기 발주서]`<br>`#{who}, 신청하신 #{days} 정기 발주서가 준비됐어요.`<br>`지난번(#{base_date}) 발주 기준 #{count}품목 · #{amount}`<br>`#{cutoff}까지 확정하시면 #{arrive} 오후에 도착해요.`<br>`▶ #{link}` |
| `BF_ACCESS_OK_02` | 품목 확인하기 | `[BevFlow 품목 이용 안내]`<br>`요청하신 #{category} 이용이 승인됐어요.`<br>`발주 화면과 카카오톡 채널의 품목 목록에 추가됐어요.`<br>`▶ #{link}` |
| `BF_ACCESS_NO_01` | — | `[BevFlow]`<br>`요청하신 #{category} 이용은 이번에 승인되지 않았어요.`<br>`사유: #{reason}`<br>`궁금한 점은 카카오톡 채널로 문의해 주세요.` |
| 식당 음료 자동 제안용 | | `BF_PROPOSE_03` · `BF_REMIND_01` · `BF_HOLD_01` · `BF_EXPIRE_01` — 문구는 `server/engine/messages.js` 참고 |

`BF_SHEET_01`(정기 발주서)은 **점주가 신청한 정기 발주의 안내**라는 점을 심사 요청서에 적어 주세요. 매장 등록 때 정기 발주 요일을 사장님과 합의해 기록해 두면 근거가 됩니다.

## 6. 운영 콘솔 입력

| 위치 | 값 |
|---|---|
| 운영 설정 → 연동 → 외부 접속 주소 | `https://ops.회사도메인.kr` |
| 운영 설정 → 점주 직접 발주·카카오 → 카카오톡 채널 ID | 2-6의 `_xxxxx` |
| 〃 → 오픈빌더 발주 블록 ID | 4-4의 24자리 |
| 〃 → 카카오 REST API 키 | 3-7 |
| 〃 → 최소 발주 금액 · 발주 화면 링크 유효 시간 | 기본 30,000원 · 24시간 |
| 운영 설정 → 정기 발주서·관리자 알림 | 발주서 09:00 · 미확정 알림 11:30 · 출고 합계 11:50 · 배송 결과 18:00 |
| 운영 설정 → 연동 → 알림 발송 방식 | 딜러사 연동 전 `콘솔`, 후 `웹훅` + URL |
| 서버 환경 변수 | `BEVFLOW_KAKAO_CLIENT_SECRET` (3-6) |
| 관리 → SKU | 품목 구분(카페·스낵·음료), 규격, **매대·소분류**(사우나: 냉장고 ① 음료 / 냉동고 · 아이스 / 온장고 · 즉석 / 과자 매대 / 안주 · 간식 / 소모품 — 정렬 순서가 곧 매대 순서) |
| 관리 → 매장 | **업종**(카페·사우나·식당), 사우나는 **정기 발주 요일**(예: 월·목), 사장님 휴대폰 |

## 7. 관리자 카톡 알림 연결 (운영자마다 한 번)

1. 콘솔 [관리 → 품목 승인·카카오 → 내 카톡 알림 → 카카오로 알림 연결하기]
2. 카카오 로그인 화면에서 **카카오톡 메시지 전송** 동의
3. 콘솔로 돌아오면 받을 알림을 고릅니다: 발주 확정 · 품목 신청 · 정기 발주서 발송 · 미확정 발주서 · 출고 합계 · 배송 결과
4. [테스트 알림 보내기] → 내 카카오톡 **나와의 채팅**에 카드가 오면 완료
5. 알림 버튼은 모바일 발주 내역 `https://ops.회사도메인.kr/a` 로 열립니다 (콘솔 로그인 필요).
6. 카카오 로그인 연장을 위해 몇 달에 한 번 [다시 연결]이 필요합니다. 만료가 가까워지면 콘솔에 남은 일수가 표시됩니다.

## 8. 점검 (실제 계정으로 한 번)

1. 테스트 매장 2곳 등록: 카페 1곳, 사우나 1곳(정기 요일 = 오늘 요일)
2. [연결 코드] 발급 → 개인 카톡에서 채널 채팅방에 6자리 전송 → "매장과 연결됐어요"
3. 카페: [💬 채팅으로 고르기] → 품목 담기 → [발주하기] → [발주 확정] → 콘솔 [발주 관제]에 `카톡 직접 발주` 카드, 내 카톡에 "✅ 발주 확정" 알림
4. 사우나: 첫 발주를 한 번 넣은 뒤 콘솔 [품목 승인·카카오 → 발주서]로 정기 발주서 보내기 → 알림톡 → [발주서 확인하기] → 몇 줄 고쳐 [확정하기] → 확인 화면에 바뀐 줄만 나오는지
5. 사우나 발주서를 확정하지 않고 두면 11:30에 "⏰ 미확정 발주서" 알림
6. 11:50 "🚚 오늘 출고 합계" 알림 → [출고 집계 전체] → 모바일 `/a#pick`
7. [➕ 품목 추가 신청] → 내 카톡 "품목 이용 신청" → [승인하러 가기] → 승인 → 점주 알림톡

## 9. 매장 온보딩 (매장마다)

1. 콘솔에서 매장 등록(업종·연락처·정기 요일) → [연결 코드] 발급
2. 점주께 보내는 문자 `[붙여넣기]`
   ```
   [BevFlow] 사장님, 카카오톡에서 'BevFlow 발주' 채널을 추가하고 채팅방에 아래 숫자 6자리를 보내 주세요.
   이후에는 채팅방 버튼만 눌러 발주하실 수 있어요.
   연결 코드: ______
   채널 바로가기: https://pf.kakao.com/_xxxxx
   ```
3. 연결되면 콘솔 매장 줄에 `💬 채널` 배지가 붙습니다.

## 카카오 쪽에서 볼 수 있는 것 / 우리 시스템에서 보는 것

- 카카오 채널 관리자센터: 1:1 채팅 대화(챗봇 메시지 포함), 친구 수·메시지 통계
- 챗봇 관리자센터: 사용자 수, 버튼(블록) 호출 순위, 호출 기록 CSV
- 딜러사 화면: 알림톡 발송 목록, 성공·실패
- **발주 내역·출고 집계·정산은 BevFlow 콘솔과 모바일 `/a`에서** 봅니다. 카카오는 발주 내용(품목·수량·금액)을 저장하지 않습니다.

## 참고: 카카오 제약과 BevFlow의 대응

| 제약 | 대응 |
|---|---|
| 스킬 응답 5초 | 발주 확정도 5초 안에 끝남 (후불 청구 기준). 카드 PG 연동 시 결제를 뒤로 미루고 "접수됨"을 먼저 답해야 함 |
| 캐러셀 최대 10장, 카드 버튼 3개, 버튼 14자 | 품목 9장 + [다른 품목 찾기], 버튼 [+1] [+5] [−1] |
| 리스트 카드 5줄 | 장바구니 4줄 + "외 N품목(발주 화면에서)" |
| 채팅 카드에 수량 입력칸 없음 | 수량 고치기·전체 보기는 발주 화면(`/m/…`), 채팅은 자주 시키는 품목·재주문·소량 추가 |
| 나에게 보내기 피드 카드: 품목 줄 5개, 버튼 2개 | 상위 4줄 + "외 N품목", 전체는 버튼으로 `/a` |
| 나에게 보내기는 본인 카톡에만 | 운영자마다 각자 연결, 알림 종류별 켜고 끄기 |
