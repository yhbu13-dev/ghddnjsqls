# 카카오 연동 — 카카오톡으로 누르기만 하는 발주

점주는 카카오톡 **BevFlow 채널**에서 글자를 치지 않고 버튼만 눌러 발주합니다. 두 가지 길이 있고, 장바구니는 서로 이어집니다.

| 길 | 쓰는 카카오 기능 | 점주가 하는 일 |
|---|---|---|
| **채팅으로 고르기** | 카카오톡 채널 + 카카오 i 오픈빌더 챗봇(스킬 서버) | 품목 카드의 [+1박스] [+5박스] 버튼 → [발주하기] → [발주 확정] |
| **한눈에 발주하기** | 채널 버튼(웹링크) → 모바일 발주 화면 `/m/…`, 카카오 로그인(선택) | 품목 탭 → − / + → [발주하기] → [발주 확정] |
| **확정·배송 안내** | 알림톡 (비즈메시지 대행사) | 받기만 하면 됨 |

## 품목과 권한

| 업종 | 기본 품목 | 다른 품목 |
|---|---|---|
| 카페 | ☕ 카페 품목 (원두·우유·시럽·컵 등) | 점주가 신청 → 운영자 승인 |
| 사우나 | 🍪 스낵 품목 (구운란·식혜·과자 등) | 점주가 신청 → 운영자 승인 |
| 식당 | 🥤 음료 품목 (탄산·생수 등) | 점주가 신청 → 운영자 승인 |

- 업종은 [관리 → 매장 → 편집]에서 정합니다. 업종 기본 품목은 항상 열려 있습니다.
- 점주는 발주 화면의 잠긴 탭(🔒 신청)이나 채팅의 [➕ 품목 추가 신청]으로 신청합니다.
- 운영자는 [관리 → 품목 승인·카카오]에서 승인·거절하고, 매장별 품목 표의 칸을 눌러 바로 열거나 닫을 수도 있습니다. 결과는 알림톡으로 안내됩니다.
- 품목 구분은 SKU마다 정합니다 ([관리 → SKU → 품목 구분]). 발주 화면에 보이는 규격 문구도 같은 곳에서 넣습니다.
- 식당 음료만 POS 판매 기반 재고 추정·자동 제안을 합니다. 카페·스낵 품목은 점주 직접 발주로만 들어옵니다.

## 1. 카카오톡 채널 만들기

1. [카카오톡 채널 관리자센터](https://center-pf.kakao.com)에서 채널을 만들고 **비즈니스 채널** 인증을 받습니다 (알림톡·챗봇 사용 조건).
2. 채널 홈 URL의 `_xxxxx` 부분이 **채널 ID**입니다. [운영 설정 → 점주 직접 발주·카카오 → 카카오톡 채널 ID]에 넣으면 발주 화면에 [채널 채팅] 버튼이 생깁니다.

## 2. 챗봇 (카카오 i 오픈빌더)

1. [오픈빌더](https://chatbot.kakao.com)에서 봇을 만들고 1의 채널을 연결합니다.
2. **스킬** → 새 스킬 → URL에 콘솔 [관리 → 품목 승인·카카오 → 오픈빌더 스킬 서버]의 주소를 붙여 넣습니다.
   `https://운영주소/api/kakao/skill?key=…` (key가 스킬 키입니다. 재발급하면 이 URL도 바꿔야 합니다)
3. **시나리오 → 블록**을 하나 만듭니다 (예: `발주`).
   - 사용자 발화: `발주`, `주문`, `장바구니`, `발주 현황`, `지난번과 똑같이`, `품목 추가 신청` 등
   - 파라미터 설정 → 스킬 선택: 2의 스킬
   - 봇 응답: **스킬데이터 사용**
4. 그 블록의 ID(블록 주소 끝 24자리)를 [운영 설정 → 오픈빌더 발주 블록 ID]에 넣습니다.
   챗봇의 모든 버튼이 이 블록으로 돌아오면서 다음 단계를 넘기므로, **블록 ID가 없으면 채팅 속 버튼 발주가 꺼지고** [한눈에 발주하기] 링크만 동작합니다.
5. **웰컴 블록 · 폴백 블록**도 봇 응답을 같은 스킬로 연결해 두면, 채널에 처음 들어오거나 아무 말을 해도 발주 메뉴가 나옵니다.
6. 채널 **메뉴(하단 고정 버튼)**에 `발주하기` → 블록 3 을 걸어 두면 점주가 채팅창을 열자마자 누를 수 있습니다.
7. 배포.

### 챗봇 흐름

```
[발주하기] ─ 홈 카드: 이용 품목 · 도착 예정 · 장바구니
   ├ 📋 한눈에 발주하기 → 모바일 발주 화면 (/m/…)
   ├ 💬 채팅으로 고르기 → 품목 탭(바로가기) → 품목 카드 캐러셀 [+1] [+5] [−1]
   │        └ 담으면: "✓ 원두 2봉 담았어요 · 🛒 3품목 · 110,000원" [계속 고르기] [장바구니] [발주하기]
   ├ 🔁 지난번과 똑같이 → 지난 발주를 장바구니에 담고 목록 표시
   ├ 🛒 장바구니 → 리스트 카드 (품목 누르면 수량 변경) [발주하기] [화면에서 수정]
   │        └ [발주하기] → 확인 카드 (품목·합계·도착 예정) [✅ 발주 확정] [✏️ 수정]
   ├ 📦 발주 현황 → 최근 5건과 상태
   └ ➕ 품목 추가 신청 → 이용하지 않는 품목 버튼 → 신청 완료
```

- [발주 확정]을 두 번 눌러도 한 번만 접수됩니다. 확인 카드를 띄운 뒤 장바구니가 바뀌면 확인 카드를 다시 보여 줍니다.
- 최소 발주 금액([운영 설정 → 최소 발주 금액], 기본 30,000원) 미만이면 확정 전에 안내합니다.
- 스킬 서버는 5초 안에 응답해야 합니다. 발주 확정(결제 포함)도 이 안에 끝나도록 결제 어댑터를 짧게 유지하세요.

## 3. 매장 연결 (처음 한 번)

챗봇은 카카오 사용자마다 다른 ID(botUserKey)를 주므로, 처음 들어온 점주를 매장과 묶어야 합니다.

1. 콘솔 [관리 → 품목 승인·카카오 → 연결 코드]로 **6자리 코드**를 발급해 점주께 전화·문자로 알려 드립니다.
2. 점주가 채널 채팅방에 그 숫자 6자리를 보내면 연결됩니다. (또는 챗봇이 보내 주는 [매장 연결하기] 화면에서 입력)
3. 코드는 한 번 쓰면 사라집니다. 매장 직원 여러 명을 연결하려면 코드를 다시 발급합니다.
4. 잘못된 코드를 10분에 5번 넘게 넣으면 잠시 막힙니다.
5. 점주가 바뀌거나 휴대폰을 잃어버리면 [초기화]로 그 매장의 카카오 연결·발주 링크를 모두 끊습니다. 연결 하나만 끊으려면 연결 배지의 ✕를 누릅니다.

## 4. 카카오 로그인 (선택 · Kakao Developers)

연결 코드 없이 **사장님 휴대폰 번호**로 자동 연결하고, 채널 밖에서도 발주 화면에 들어올 수 있게 합니다.

1. [카카오 디벨로퍼스](https://developers.kakao.com) → 내 애플리케이션 → 앱 만들기.
2. **앱 키 → REST API 키**를 [운영 설정 → 카카오 REST API 키]에 넣습니다.
3. **플랫폼 → Web** 사이트 도메인에 운영 주소(`https://운영주소`)를 등록합니다.
4. **카카오 로그인** 활성화 → **Redirect URI**에 `https://운영주소/k/callback` 등록 (콘솔 [품목 승인·카카오]에 표시된 값).
5. **동의항목** → `카카오계정(전화번호)`를 필수 또는 선택 동의로 켭니다 (비즈 앱 전환 필요). 켜면 카카오 계정 번호와 매장의 사장님 휴대폰 번호가 **정확히 한 매장과** 일치할 때 자동 연결됩니다. 일치하지 않으면 연결 코드 입력 화면으로 넘어갑니다.
6. (권장) **보안 → Client Secret** 발급 후 '사용함'으로 켜고, 값을 환경 변수 `BEVFLOW_KAKAO_CLIENT_SECRET`에 넣습니다.
7. (권장) **카카오톡 채널 연결**: 앱 설정의 [카카오톡 채널]에 1의 채널을 연결하면, 카카오 로그인을 한 번 한 점주는 챗봇 요청에 `appUserId`가 함께 와서 **채널에서도 연결 코드 없이** 바로 인식됩니다.

로그인 시작 주소는 `https://운영주소/k/login`입니다. 채널 메뉴나 홈페이지에 걸어 둘 수 있습니다.

## 5. 알림톡

발주 확정·배송 완료·품목 승인 안내는 알림톡(비즈메시지)으로 나갑니다. 대행사 계약 전에는 **콘솔 모드**로 [알림톡 모니터]에서 복사해 전달하고, 계약 후 **웹훅 모드**로 바꿉니다. 등록할 템플릿 목록은 `docs/INTEGRATIONS.md` 2장에 있습니다.

## 점검 순서

1. 테스트 매장(업종 카페)을 만들고 연결 코드를 발급합니다.
2. 개인 카카오톡으로 채널을 추가하고 채팅방에 코드 6자리를 보냅니다 → "매장과 연결됐어요".
3. [💬 채팅으로 고르기] → 품목 담기 → [발주하기] → [발주 확정] → 콘솔 [발주 관제]의 **결제 완료** 열에 `카톡 직접 발주` 배지가 붙은 카드가 생기는지 확인합니다.
4. [📋 한눈에 발주하기]로 화면을 열어 같은 장바구니가 이어지는지 확인합니다.
5. [➕ 품목 추가 신청 → 스낵] → 콘솔 [품목 승인·카카오]에 신청이 뜨는지, 승인하면 발주 화면에 스낵 탭이 열리는지 확인합니다.
