# 투스타 발주

카페·사우나·식당 점주가 **카카오톡 채널 "투스타글로벌(발주)"** 에서 버튼만 눌러 발주하는 프로그램입니다.
기존 BevFlow와는 별개의 새 프로그램이며, 외부 패키지 없이 Node.js만 있으면 돌아갑니다.

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 점주 | 카카오톡 채널 챗봇 | 품목 골라 담기 · 장바구니 · 주문 확정 · 지난 발주 그대로 · 발주 내역 · 품목 추가 신청 |
| 점주 | 발주서 (카톡 [발주서 열기] 버튼) | 품목 전체를 한 장에서 +/− 로 수정. 사우나는 지난 발주 수량이 미리 채워짐 |
| 관리자 | `/admin` | 새 주문 확인 → 확인 → 출고 → 납품완료 · 출고 집계(인쇄) · 품목 승인 · 매장/연결 코드 · 품목 관리 |

## 품목 규칙

- 업종별 기본 품목: **카페 → 카페 품목, 사우나 → 사우나 스낵, 식당 → 식당 음료**
- 다른 품목은 점주가 [품목 추가 신청] → 관리자가 [품목 승인] 탭에서 승인해야 보입니다. 승인을 해제하면 장바구니에서도 빠집니다.
- 같은 주문을 두 번 눌러도 한 번만 접수됩니다 (장바구니 버전 확인).

## 1. 내 Mac에서 켜기 (데모)

1. https://nodejs.org 에서 **LTS** 버전을 내려받아 설치합니다 (처음 한 번)
2. 터미널에서 이 폴더로 이동한 뒤 실행합니다:

```bash
bash start-mac.sh
```

스크립트가 알아서 cloudflared 를 내려받고, 외부 https 주소를 만들고, 관리자 비밀번호와 스킬 키를 만들고(`data/settings.env`), 서버를 켭니다.
화면에 나오는 **관리자 주소 · 비밀번호 · 오픈빌더 스킬 URL** 을 사용하세요. 스킬 URL 은 클립보드에 복사되어 있습니다.

- 창을 닫거나 Mac 이 잠들면 챗봇이 멈춥니다 (실행 중에는 잠자기를 막아 둡니다).
- 다시 켤 때마다 주소가 바뀝니다 → 오픈빌더 스킬 URL 을 다시 붙여넣고 배포해 주세요. 실제 운영은 고정 주소(서버·도메인)로 옮깁니다.
- 처음부터 다시 하려면 `data` 폴더를 지웁니다 (주문·매장 데이터도 지워집니다).

## 2. 카카오 i 오픈빌더 연결 (투스타발주봇)

1. **스킬 → 스킬 목록 → 생성**: 이름 `발주서버`, URL = 서버가 알려준 `https://…/kakao/skill?key=…` → 저장
2. **시나리오 → 발주 블록**: 파라미터 설정의 스킬에서 `발주서버` 선택 → 봇 응답을 **스킬데이터 사용** → 저장
3. **폴백 블록**: 같은 방법으로 스킬 `발주서버` + 스킬데이터 사용 (점주가 연결 코드 6자리를 입력하면 여기로 들어옵니다)
4. **웰컴 블록**: 켜고 스킬데이터 사용 (채널을 처음 추가하면 첫 화면이 바로 나옵니다)
5. **배포 → 배포하기**

`BLOCK_ID` 는 발주 블록 ID 입니다 (블록 주소 `…/intent/<블록ID>` 의 마지막 부분). 모든 버튼이 이 블록으로 돌아와 서버가 다음 화면을 정합니다.

## 3. 점주 연결

1. 관리자 → **매장** → 매장 추가 → 6자리 **연결 코드** 가 나옵니다
2. 점주가 카카오톡에서 "투스타글로벌(발주)" 채널 추가 → 채팅창에 6자리 입력 → 연결 완료
3. 이후 점주는 버튼만 누릅니다. 코드는 한 번 쓰면 사라지고, 다시 필요하면 [연결 코드] 로 새로 받습니다.

## 설정 (환경 변수)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 8080 | |
| `PUBLIC_URL` | http://localhost:8080 | 발주서 링크에 들어가는 외부 주소 |
| `ADMIN_PASSWORD` | (없으면 임시 비밀번호 출력) | 관리자 로그인 |
| `SKILL_KEY` | (없으면 스킬 꺼짐) | 오픈빌더 스킬 URL 의 key |
| `BLOCK_ID` | | 발주 블록 ID |
| `MIN_ORDER` | 0 | 최소 발주 금액(원) |
| `GUEST_URL` / `GUEST_LABEL` | | 연결 안 된 손님에게 보여줄 안내 버튼 (예: 쇼핑몰) |
| `DATA_DIR` / `DB_FILE` | data/ | 저장 위치 |
