# 투스타 발주

카페·사우나·식당 점주가 **카카오톡 채널 "투스타글로벌(발주)"** 에서 버튼만 눌러 발주하는 프로그램입니다.
기존 BevFlow와는 별개의 새 프로그램이며, 외부 패키지 없이 Node.js만 있으면 돌아갑니다.

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 점주 | 카카오톡 채널 챗봇 | 품목 골라 담기 · 장바구니 · 주문 확정 · 지난 발주 그대로 · 발주 내역 · 품목 추가 신청 |
| 점주 | 발주서 (카톡 [발주서 열기] 버튼) | 품목 전체를 한 장에서 +/− 로 수정. 사우나는 지난 발주 수량이 미리 채워짐 |
| 관리자 | `/admin` | 새 주문 확인 → 확인 → 출고 → 납품완료 · 출고 집계(인쇄) · 품목 승인 · 매장/연결 코드 · 품목 관리 |

## 품목 규칙

- 업종별 기본 품목: **카페 → 카페 품목, 사우나 → 사우나 스낵, 식당 → 식당 음료**
- 다른 품목은 점주가 [품목 추가 신청] → 관리자가 [품목 승인] 탭에서 승인해야 보입니다. 승인을 해제하면 장바구니에서도 빠집니다.
- 같은 주문을 두 번 눌러도 한 번만 접수됩니다 (장바구니 버전 확인).

## 0. Cloudflare 에 올리기 — 운영 권장

PC 를 켜 둘 필요 없고 주소(`https://twostar-order.○○.workers.dev`)가 바뀌지 않습니다.
Cloudflare Workers(서버) + D1(데이터베이스)을 쓰며, 이 규모는 무료 한도 안에서 운영됩니다.

1. Windows 에서 `twostar-order` 폴더의 **`deploy-cloudflare.bat`** 더블클릭 (Mac: `node scripts/deploy-cloudflare.js`)
2. 브라우저가 열리면 Cloudflare 로그인 → **Allow**
3. 관리자 비밀번호(8자 이상) 입력
4. 화면에 나온 **관리자 주소**와 **오픈빌더 스킬 URL**(클립보드에 복사됨)을 사용 → 오픈빌더 스킬 URL 교체 → 배포

- 코드를 새로 받은 뒤 같은 파일을 다시 실행하면 업데이트됩니다. 데이터(D1)는 그대로입니다.
- 스킬 URL 은 관리자 화면 **[매장] 탭 맨 위**에서도 언제든 복사할 수 있습니다.
- 카톡 요청 기록: Cloudflare 대시보드 → Workers → twostar-order → **Logs**
- 실제 운영 전: `wrangler.toml` 의 `SEED_SAMPLE` 을 `"0"` 으로 바꾸고 다시 배포, 샘플 매장은 [숨기기]

## 0-1. (대안) Render 에 올리기

PC 를 켜 둘 필요 없고 주소가 바뀌지 않습니다. 저장소 맨 위의 `render.yaml` 이 설정을 모두 담고 있습니다.

1. https://render.com → **GitHub 로 가입/로그인** → 결제 카드 등록 (Starter $7/월 + 디스크 1GB $0.25/월)
2. **New → Blueprint** → 이 저장소 선택 (처음이면 GitHub 에서 Render 접근 허용) → 브랜치 선택 → `render.yaml` 인식
3. **ADMIN_PASSWORD** 입력 (8자 이상) → **Apply**
4. 배포가 끝나면(3~5분) 서비스 화면 위쪽의 주소 `https://twostar-order-xxxx.onrender.com` 이 고정 주소
5. **Environment** 탭에서 `SKILL_KEY` 값을 복사 → 오픈빌더 스킬 URL: `https://<고정 주소>/kakao/skill?key=<SKILL_KEY>` → 저장 → **배포**
6. 관리자 화면: `https://<고정 주소>/admin`

- 데이터(주문·매장·품목·사진)는 Render 디스크(`/var/data`)에 저장되고 다시 배포해도 유지됩니다. Render 가 디스크 스냅샷을 매일 남깁니다.
- 저장소에 새 코드가 올라오면 자동으로 다시 배포됩니다 (1~3분, 그동안 잠깐 응답이 늦을 수 있음).
- 실제 운영 전: Environment 에서 `SEED_SAMPLE` 을 `0` 으로 바꾸고, 관리자 → 매장 [숨기기] 로 샘플 매장을 정리하세요.

## 1. 내 Mac에서 켜기 (데모)

1. https://nodejs.org 에서 **LTS** 버전을 내려받아 설치합니다 (처음 한 번)
2. 터미널에서 이 폴더로 이동한 뒤 실행합니다:

```bash
bash start-mac.sh
```

스크립트가 알아서 cloudflared 를 내려받고, 외부 https 주소를 만들고, 관리자 비밀번호와 스킬 키를 만들고(`data/settings.env`), 서버를 켭니다.
화면에 나오는 **관리자 주소 · 비밀번호 · 오픈빌더 스킬 URL** 을 사용하세요. 스킬 URL 은 클립보드에 복사되어 있습니다.

- 창을 닫거나 Mac 이 잠들면 챗봇이 멈춥니다 (실행 중에는 잠자기를 막아 둡니다).
- 다시 켤 때마다 주소가 바뀝니다 → 오픈빌더 스킬 URL 을 다시 붙여넣고 배포해 주세요. 실제 운영은 고정 주소(서버·도메인)로 옮깁니다.
- 처음부터 다시 하려면 `data` 폴더를 지웁니다 (주문·매장 데이터도 지워집니다).

## 1-W. Windows PC에서 켜기 (데모)

1. https://nodejs.org 에서 **LTS** 버전(Windows Installer)을 설치합니다 (처음 한 번)
2. 받은 zip 을 **압축 풀기** 한 뒤 `twostar-order` 폴더의 **`start-windows.bat`** 을 더블클릭합니다
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**
3. 검은 창에 **관리자 주소 · 비밀번호 · 오픈빌더 스킬 URL** 이 나옵니다 (스킬 URL 은 클립보드에 복사됨)

- 창을 닫거나 PC 가 꺼지면 챗봇이 멈춥니다 (실행 중에는 절전을 막아 둡니다). 끄기: `Ctrl + C`
- 서버는 이 PC 안(127.0.0.1)에서만 받고, 외부 연결은 cloudflared 터널이 맡습니다 → 방화벽 경고 창이 뜨지 않습니다.

## 2. 카카오 i 오픈빌더 연결 (투스타발주봇)

1. **스킬 → 스킬 목록 → 생성**: 이름 `발주서버`, URL = 서버가 알려준 `https://…/kakao/skill?key=…` → 저장
2. **시나리오 → 발주 블록**: 파라미터 설정의 스킬에서 `발주서버` 선택 → 봇 응답을 **스킬데이터 사용** → 저장
3. **폴백 블록**: 같은 방법으로 스킬 `발주서버` + 스킬데이터 사용 (점주가 연결 코드 6자리를 입력하면 여기로 들어옵니다)
4. **웰컴 블록**: 켜고 스킬데이터 사용 (채널을 처음 추가하면 첫 화면이 바로 나옵니다)
5. **배포 → 배포하기**

`BLOCK_ID` 는 발주 블록 ID 입니다 (블록 주소 `…/intent/<블록ID>` 의 마지막 부분). 모든 버튼이 이 블록으로 돌아와 서버가 다음 화면을 정합니다.

## 3. 점주 연결

1. 관리자 → **매장** → 매장 추가 → 6자리 **연결 코드** 가 나옵니다
2. 점주가 카카오톡에서 "투스타글로벌(발주)" 채널 추가 → 채팅창에 6자리 입력 → 연결 완료
3. 이후 점주는 버튼만 누릅니다. 코드는 한 번 쓰면 사라지고, 다시 필요하면 [연결 코드] 로 새로 받습니다.

## 4. 발주 확인 · 문서 · 카톡 알림

- **주문 → [확인 처리]** 를 누르면 점주 카톡으로 "✅ 발주가 확인되었어요 · 도착 예정일"이 갑니다 (출고 · 취소도 알림).
- **📄 확인서 / 🧾 명세서**: 주문마다 버튼. 매장 → [발주 내역 · 명세서] 에서 월별 내역과 기간 거래명세서. 모두 [인쇄 · PDF 저장].
- **설정** 탭: 회사 정보(명세서 공급자 칸) · 배송 기간(기본 2~3일, 주말 제외) · 부가세 방식 · 카톡 자동 알림.
- 카톡 자동 알림은 카카오 챗봇 **Event API** 를 씁니다. 설정 전에는 알림이 쌓여 있다가 점주가 채팅방에서 버튼을 누르면 맨 위에 보입니다.
  1. developers.kakao.com 에서 앱 생성 → REST API 키
  2. 오픈빌더 → 챗봇 설정에서 Event API 사용 (그 앱 연결)
  3. 오픈빌더에 새 블록을 만들고 이벤트 이름 `order_notice` · 응답은 스킬(발주서버) → 배포
  4. 관리자 → 설정 → 봇 ID(오픈빌더 주소 `bots/` 뒤) · REST API 키 저장 → 매장 상세 [알림 테스트]
  - 채널을 추가(친구)한 점주에게만 갑니다.

## 설정 (환경 변수)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 8080 | |
| `PUBLIC_URL` | http://localhost:8080 | 발주서 링크에 들어가는 외부 주소 |
| `ADMIN_PASSWORD` | (없으면 임시 비밀번호 출력) | 관리자 로그인 |
| `SKILL_KEY` | (없으면 스킬 꺼짐) | 오픈빌더 스킬 URL 의 key |
| `BLOCK_ID` | | 발주 블록 ID |
| `MIN_ORDER` | 0 | 최소 발주 금액(원) |
| `GUEST_URL` / `GUEST_LABEL` | | 연결 안 된 손님에게 보여줄 안내 버튼 (예: 쇼핑몰) |
| `DATA_DIR` / `DB_FILE` | data/ | 저장 위치 |

## 개발

```bash
npm test
```

구성: `src/order.js`(발주 규칙) · `src/kakao.js`(챗봇 화면) · `src/app.js`(요청 처리·관리자) · `public/`(발주서·관리자 화면)
실행 환경: `src/server.js`(내 컴퓨터·Render, SQLite 파일) · `src/worker.mjs`(Cloudflare Workers, D1) — 같은 코드를 씁니다.
